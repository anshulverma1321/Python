# 🚀 Complete Python Course Repository

A structured and hands-on Python learning repository covering concepts from **basics to advanced topics**.
This repository is organized in a modular format to help you learn Python step by step.

---

## 📂 Repository Structure

```
.
├── 00_python                # Introduction & basics
├── 01_virtual              # Virtual environments
├── 02_datatypes            # Data types in Python
├── 03_conditionals         # If-else & control flow
├── 04_loops                # Loops (for, while)
├── 05_functions            # Functions & scope
├── 06_chai_business        # Real-world examples
├── 07_comprehensions       # List/Dict comprehensions
├── 08_generators           # Generators & iterators
├── 09_decorators           # Decorators
├── 10_oop                  # Object-Oriented Programming
├── 11_exceptions           # Exception handling
├── 12_threads_concurrency  # Multithreading & concurrency
├── 13_async_python         # Async programming
├── 14_pydantic             # Data validation using Pydantic
├── challenges              # Practice problems
```

## ⚙️ How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/anshulverma1321/Python.git
   ```

2. Navigate to any module:

   ```bash
   cd 04_loops
   ```

3. Run Python files:

   ```bash
   python filename.py
   ```
